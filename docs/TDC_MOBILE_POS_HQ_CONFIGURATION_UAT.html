Mobile POS — HQ configuration before using the app

This guide tells the HQ administrator exactly where each prerequisite is configured, what values are required, how the configuration connects to Mobile POS, and what must be visible before a cashier starts using the Android app.

Use the deployed VPS address. Every route below is shown with the current UAT host, https://63.141.230.56. Complete this guide only after the deployment workflow has succeeded and the six Mobile POS database migrations have been applied.
Two controls apply to every operator. Giving a user Mobile POS permissions does not assign the user to a store. Assigning a user to a store does not grant permissions. HQ must complete both.
Recommended first UAT scope. Configure the first store as Online only. Printer and dedicated scanner hardware are not required for the first test; use item search, camera/manual identifier entry, receipt view, PDF/system print, or share fallback.

2. Configure roles and permissions

Settings → Administration & Governance → Security & Identity → Role Managementhttps://63.141.230.56/administration/identity-management/roles

  1. Open the role assigned to the cashier. The role name may be any management-defined name.
  2. Use the permission search box to find MobilePOS and Finance.
  3. Grant the permissions required for the tasks that role performs.
  4. Save the role, then verify the intended user is assigned to that role under Identity Management → Users.

5. Create the Mobile POS till

Settings → Administration & Governance → General Administration → Mobile POS → Tillshttps://63.141.230.56/administration/mobile-pos

  1. Click Add till.
  2. Select the active Mobile POS store.
  3. Select the active CashTill liquidity account created in step 1.5.
  4. Enter a unique till number and name.
  5. Set status to Active.
  6. Under Accepted payment methods, tick every tender the till may accept.
  7. For each selected tender, set Online, Offline, and External reference deliberately.
  8. Click Save till.
Validation rules. Store and till currency must match. A CashTill liquidity account can belong to only one non-retired Mobile POS till. The store must be Active before its till can be Active.

6. Assign the operator to the store

Settings → Administration & Governance → General Administration → Mobile POS → User assignmentshttps://63.141.230.56/administration/mobile-pos

  1. Click Assign user.
  2. Search for and select the active tenant user.
  3. Select the active store.
  4. Set Effective from to the approved start time.
  5. Set Effective to only if the assignment must expire automatically.
  6. Enter an assignment reason and save.

PASS: The assignment is current, not expired, and points to the same store that will be assigned to the device. Saving a new current assignment closes the prior current store assignment.
