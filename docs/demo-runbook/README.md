# Demo runbook — HR and SHE modules

Print-ready HTML. Open each file in a browser and **Ctrl+P → Save as PDF** (A4, default margins,
background graphics on). Read on the second laptop in order.

| File | Use |
| --- | --- |
| `book-0-demo-day-operations.html` | Bring-up, logins, the database check, recovery. Read first. |
| `book-1-core-hr.html` | Employees, organisation, job architecture, manpower budget, recruitment, orientation, probation |
| `book-2-operations-hr.html` | Leave, attendance, travel, assets, medical, benefits, company schedule, consulting |
| `book-3-development-and-governance.html` | Performance, training, competencies, succession, awards, movements, discipline, employee relations, separation, policies, the portal |
| `book-4-safety-health-environment.html` | The whole SHE module |
| `cheat-sheet.html` | One page: logins, commands, named records, queues, never-click list |

The records the books cite exist in `ErpSystemDB_UAT` after `scripts/New-UatDatabase.ps1` and
`dev-harness/hr-demo-smoke/scenarios.mjs` — see `docs/UAT-DEMO-DATABASE.md`.
