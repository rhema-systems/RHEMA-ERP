# Finance Go-Live Limitations Register

Date created: 2026-07-06

This is the single running register for deferred Finance go-live work, accepted workarounds, partial implementations, and diagnostic items that must not be lost between batches.

Blocking interpretation:

- `Go-live blocking = Yes` means the item must be resolved before final Finance go-live unless accounting/product leadership explicitly accepts it as non-blocking.
- `Blocks next batch = Yes` means the next planned implementation batch should not proceed until the item is resolved because it would compromise that batch's correctness, tests, or architecture.
- A go-live-blocking item may remain open across multiple batches if it does not weaken the immediate next batch.
- Future Finance batch PR summaries must reference limitation IDs for any new, changed, or resolved limitation.
